# Project knowledge base

This directory stores concise, durable project context for future work. Start at [index.md](index.md) and load only the topic needed.

Active canonical notes live in `topics/`; superseded notes belong in `archive/`. Keep competition assets, frame-level extracts, credentials, candidate predictions, and accuracy claims out of this knowledge base. Mark whether statements are verified from repository evidence or carried forward from prior records.

Every topic includes provenance. Handoffs are intake records, not the default
retrieval layer; canonical durable knowledge belongs in `topics/`. Refresh the
index when topics change and preserve useful history by archiving superseded
material rather than deleting it. Keep restricted assets, frame-level data,
candidate outputs, and credentials out of all active and archived notes.
